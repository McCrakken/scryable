# Scryable Mobile App

The shopper-facing React Native (Expo) app for browsing second-hand video game store inventory.

## Tech Stack

- **Framework:** React Native via Expo SDK 53
- **Routing:** Expo Router (file-based)
- **Shared Types:** `@scryable/shared` (monorepo workspace)
- **Language:** TypeScript 6

## Getting Started

### Prerequisites
- Node.js >= 18
- Expo CLI (`npx expo` — no global install needed)
- Expo Go app on your phone (iOS App Store / Google Play)

### Install & Run

From the **monorepo root**:

```bash
yarn install
yarn mobile
```
